# Design Tokens

Toda la consistencia visual del DS sale de variables CSS `--ig-*`. Cambiar una
variable en `:root` cambia la apariencia en todos los componentes que la usan
— es el punto canónico para customización por aplicación consumidora.

## Colores semánticos

Cada variante semántica está respaldada por un color base con nombre latino.
Las variantes son las que aparecen en `Button`, `Badge`, `Spinner`, `Alert`…

## Espaciado

Todos los espaciados son múltiplos de `--ig-space-unit` (por defecto `0.25rem`
= 4px). Disponibles: `0, 0-5, 1, 1-5, 2, 2-5, 3, 3-5, 4, 5, 6, 7, 8, 9, 10, 11,
12, 14, 16, 20, 24, 28, 32, 36, 40`.

<div style={{ margin: "1.5rem 0" }}>

    <div
      key={n}
      style={{
        display: "flex",
        alignItems: "center",
        gap: "0.75rem",
        marginBottom: 4,
        fontFamily: "var(--ig-font-mono, monospace)",
        fontSize: 12,

          background: "var(--ig-brand)",
          height: 16,

    </div>
  ))}
</div>

## Cómo customizar

Override en tu `:root` para reemplazar valores globalmente:

```css
:root {
  --ig-brand: #5b21b6;       /* tu morado de marca */
  --ig-space-unit: 0.3rem;   /* escalar todo el spacing */
  --ig-font-base: "Inter", system-ui, sans-serif;
}
```

Si solo quieres tocar un componente concreto, override por scope CSS:

```css
.mi-vista .ig-btn {
  --ig-btn-radius: 999px;
}
```
