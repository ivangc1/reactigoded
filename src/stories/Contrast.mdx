# Contraste y accesibilidad

Todos los pares texto+fondo del DS cumplen **WCAG AA** (≥4.5:1 para texto
normal, ≥3:1 para texto grande/elementos UI). El contraste lo verifica
`axe-core` en cada story de Storybook (las violaciones rompen la build).

> El comentario histórico de "WCAG AAA" en `igoded-design.css` se corrigió a
> AA en `1.0.0-beta.1`. La keyword en `package.json` también es `wcag-aa`. Si
> ves "AAA" en algún sitio, es legacy.

## Garantías a11y verificadas en CI

- **`prefers-reduced-motion`**: regla universal en `igoded-design.css` que
  reduce a `0.01ms` la duración de animaciones y transiciones para usuarios
  con motion sensitivity. Modal `<dialog>` tiene override específico que
  cancela `animation` también.
- **`prefers-contrast: more`**: bordes refuerzan a 2px (`.ig-btn`, `.ig-input`,
  `.ig-card`), `currentColor` en bordes default/subtle.
- **`forced-colors: active` (Windows High Contrast Mode)**: focus-visible usa
  `Highlight` system color; bordes usan `currentColor`.
- **`axe-core` en cada story**: 175 stories pasan auditoría completa de a11y
  (incluye violaciones de contraste — las atrapa el `addon-a11y` con `test:
  "error"`).

## Override por consumer

Si tu marca exige contrastes mayores (AAA estricto) o cambias paleta,
sobreescribe los tokens `--ig-text-*` en `:root`:

```css
:root {
  /* Forzar texto muted más oscuro = mejor contraste sobre bg-muted. */
  --ig-text-muted: #4a4452;       /* light theme */
}

[data-theme="dark"] {
  --ig-text-muted: #9aafaf;       /* dark theme */
}
```

Mantén siempre el ratio 4.5:1 mínimo (mide con
[contrast-ratio.com](https://contrast-ratio.com) o las DevTools de Chrome).
