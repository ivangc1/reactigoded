# Espaciado

Toda la escala de espaciado del DS sale de `--ig-space-unit` (por defecto
`0.25rem` = 4px). Cada token `--ig-space-*` es un múltiplo: `--ig-space-4`
es `calc(var(--ig-space-unit) * 4)` = `1rem` = 16px.

Cambia `--ig-space-unit` en `:root` para escalar TODO el espaciado de tu app
sin tocar componentes.

## Cómo usar

### Como token CSS

```css
.mi-componente {
  padding: var(--ig-space-3) var(--ig-space-4);
  gap: var(--ig-space-2);
  margin-block-end: var(--ig-space-6);
}
```

### Como utility class

`igoded-state-css.css` expone utilities con sufijos numéricos correlacionados
(divididos por 4 al usar el sufijo Tailwind-like):

```html
<div class="ig-p-3 ig-gap-2 ig-mb-6">…</div>
```

| Token              | Valor         | Utility          | Tailwind equivalente |
| ------------------ | ------------- | ---------------- | -------------------- |
| `--ig-space-1`     | 4px (0.25rem) | `ig-{p,m,gap}-1` | `1`                  |
| `--ig-space-2`     | 8px           | `…-2`            | `2`                  |
| `--ig-space-4`     | 16px          | `…-4`            | `4`                  |
| `--ig-space-8`     | 32px          | `…-8`            | `8`                  |
| `--ig-space-16`    | 64px          | `…-16`           | `16`                 |

## Customizar

```css
:root {
  /* Diseño más compacto: todo a 80%. */
  --ig-space-unit: 0.2rem;

  /* O más espacioso. */
  --ig-space-unit: 0.3rem;
}
```

> Recomendación: no cambies tokens individuales (`--ig-space-3`,
> `--ig-space-4`…) salvo casos puntuales. Cambia `--ig-space-unit` para
> mantener proporciones y consistencia.

## Cuándo usar qué

| Caso                                       | Token recomendado                        |
| ------------------------------------------ | ---------------------------------------- |
| Padding interno de un control compacto     | `--ig-space-2` / `--ig-space-3`          |
| Padding interno de Card / Dialog            | `--ig-space-4` / `--ig-space-6`          |
| Gap entre items en una lista               | `--ig-space-2` / `--ig-space-3`          |
| Gap entre secciones en una página          | `--ig-space-8` / `--ig-space-12`         |
| Margen entre sección y siguiente           | `--ig-space-12` / `--ig-space-16`        |
| Spacing en mobile (compacto)               | `--ig-space-2` / `--ig-space-3`          |
