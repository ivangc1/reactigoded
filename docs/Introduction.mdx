# Igoded Design System

Componentes React tipados + sistema CSS utility-first state-driven.

- ⚛️ React 19 + TypeScript estricto
- 🎨 CSS variables con tokens semánticos (`--ig-*`)
- 🌗 Light / dark via atributo `data-theme` en `<html>`
- ♿ A11y validado con `axe-core` en cada story
- 🧪 Tests unitarios (Vitest happy-dom) + interaction tests (browser via Playwright)

## Instalación

> **Nota**: el paquete aún no está publicado a npm. Mientras tanto,
> instalación local vía clone + `npm link`:

```bash
git clone https://github.com/ivangc1/reactigoded.git
cd reactigoded
npm ci --legacy-peer-deps
npm run build
npm link

# en tu app:
cd /tu/app
npm link reactigoded
```

## Uso

### 1. Importa los estilos una sola vez en tu app

```tsx
// _app.tsx, layout.tsx, main.tsx… una sola vez.
// Mínimo necesario para que los componentes se vean (incluye tokens + base
// + components vía @import interno):
import "reactigoded/styles/design.css";

// Opcional: estilos por defecto para HTML nativo (h1-h6, p, a, table…).
// NO lo importes si ya usas Tailwind preflight, Bootstrap reboot u otro reset.
import "reactigoded/styles/reset.css";

// Opcional: utilities pseudo-class (`hover:ig-bg-brand`, `focus:…`, etc.).
// ~6.5 MB sin gzip / ~700 KB gzipped — solo si usas las utilities directamente en HTML.
import "reactigoded/styles/state.css";

// Tipografías Google Fonts oficiales del DS (Electrolize / Saira /
// JetBrains Mono). Opt-in desde 1.0.0-beta.3 — antes el `tokens.css` las
// metía implícitamente. Si no la importas, tipografía cae a system-ui.
// import "reactigoded/styles/fonts.css";

// Granular (avanzado): solo tokens, o tokens + base sin components.
// import "reactigoded/styles/tokens.css";
// import "reactigoded/styles/base.css";
// import "reactigoded/styles/components.css";

// Atajo: design + reset + state vía @import (sin duplicar bytes).
// import "reactigoded/styles/all.css";
```

### 2. Usa los componentes

```tsx
import { Button, Badge, Spinner } from "reactigoded";

export function MiVista() {
  return (
    <>
      <Button variant="brand">Aceptar</Button>
      <Badge variant="success" pill>OK</Badge>
      <Spinner size="lg" />
    </>
  );
}
```

### 3. Cambio de tema

El tema se controla con el atributo `data-theme` en `<html>`. Para cambiarlo
puedes usar el hook que viene incluido:

```tsx
import { useTheme } from "reactigoded";

export function ThemeToggle() {
  const { theme, toggleTheme } = useTheme();
  return (
    <button onClick={toggleTheme}>
      {theme === "dark" ? "☀️" : "🌙"}
    </button>
  );
}
```

## Convenciones

- **Nombres de clase**: todas las clases del DS empiezan por `ig-` (`ig-btn`, `ig-card`, `ig-flex`…). Esto evita choques con Tailwind, Bootstrap o cualquier otra librería de utilidades.
- **Variantes**: las 6 variantes semánticas (`brand`, `secondary`, `success`, `warning`, `danger`, `info`) están alineadas en todos los componentes. Cada una mapea a un color cardinal: `brand→vitreus`, `secondary→axis`, `success→laurus`, `warning→rutilus`, `danger→malum`, `info→kobalium` (azul cobalto propio; antes alias de `axis`, separado en `1.0.0-beta.3` y reasignado de cyan H≈214° a cobalt H≈260° en `1.0.0-beta.7` para separarlo perceptualmente de `vitreus`).
- **Tamaños**: `xs` · `sm` · `md` (default) · `lg` · `xl`. `md` no añade clase modificadora.
- **`ref` como prop normal**: aprovechamos React 19; no hace falta `forwardRef`.
- **Type-safe**: cada componente exporta su tipo `Props` y los unions de variantes/sizes para reutilizar en tu app.

## Testing

El paquete se valida internamente con tres niveles:

1. **Tests happy-dom** — comportamiento de cada componente, render condicional, refs.
2. **Stories como tests** — `addon-vitest` ejecuta cada story en Chromium real, captura regresiones de render y corre las funciones `play()` como interaction tests.
3. **A11y** — `addon-a11y` corre `axe-core` en cada story; las violaciones rompen la build.

Antes de publicar:

```bash
npm run verify   # lint + typecheck + tests + build
```
